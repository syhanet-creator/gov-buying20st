# 나라장터 입찰공고 검색 (gov-buying20st)

조달청 나라장터 입찰공고를 **공사·용역·물품** 한 화면에서 조건 검색하고, 3분마다 자동 갱신하는 웹앱.

## 검색 조건
| 조건 | 설명 |
|---|---|
| 입찰 유형 | 공사 / 용역 / 물품 (복수 선택) |
| 기간 | 오늘·3일·7일·14일·31일 또는 직접 날짜 지정 (최대 31일), 공고게시일 / 개찰일시 기준 |
| 지역 | 17개 시·도. 참가제한·공사현장 지역과 수요기관·공고기관·공고명에서 매칭 |
| 기관·지역 키워드 | 예: 울주군, 한국수력원자력 |
| 품목·키워드 | 공고명에 포함된 단어 (여러 단어는 모두 포함) |
| 추정금액 | 구간 선택 또는 최소·최대(만원) 직접 입력 |
| 정렬 | 최신 공고순 / 마감 임박순 / 금액 높은순 |

마지막으로 검색한 조건은 브라우저에 저장됩니다. 기본은 최근 3일·전체 유형·최신순 20건이며 "더 보기"로 20건씩 늘어납니다.

## 구성
- `index.html` — 화면
- `api/bids.js` — Vercel 서버리스 함수 (공공데이터포털 API 호출, 인증키 은닉, 필터링)
- `package.json` — ESM 설정
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA (홈 화면 설치, 오프라인 화면, 아이콘)
- `vercel.json` — 서비스워커·매니페스트 헤더

## 앱으로 설치 (PWA)
- **안드로이드 Chrome**: 화면 상단의 "📲 앱 설치" 버튼, 또는 메뉴 → 홈 화면에 추가
- **아이폰 Safari**: 공유 버튼 → 홈 화면에 추가
- 설치하면 주소창 없이 앱처럼 열리고, 마지막으로 본 목록이 먼저 표시된 뒤 새로 갱신됩니다. 오프라인이면 저장된 목록이 보입니다 (새 공고는 온라인에서만 조회).

## 배포
1. 공공데이터포털(data.go.kr)에서 **조달청_나라장터 입찰공고정보서비스** 활용신청 → 인증키 확인
2. GitHub 저장소를 Vercel에서 Import
3. Vercel → Settings → Environment Variables
   - `DATA_GO_KR_KEY` = 발급받은 인증키 (필수)
   - `BID_API_BASE` = (선택) 기본값 `https://apis.data.go.kr/1230000/ad/BidPublicInfoService`
4. 재배포

키가 없으면 샘플 데이터가 표시됩니다.

## Supabase 저장 (수집본 검색)
공공데이터포털 API는 호출 한도·응답 지연이 있어, 공고를 Supabase DB에 모아 두고 거기서 검색합니다.
- **수집**: Edge Function `sync-bids`가 pg_cron으로 10분마다 최근 구간을 가져와 `g2b_bids`에 upsert (120일 지난 공고는 매일 삭제)
- **검색**: 화면이 공개(publishable) 키로 RPC `g2b_search_bids`만 호출 (테이블은 RLS로 읽기 전용, 수집 로그는 비공개)
- **대체 경로**: DB가 비었거나, 3시간 넘게 갱신이 없거나, 조회 시작일이 수집 시작일보다 앞서면 기존 `/api/bids`(실시간 API)로 자동 전환
- **시크릿**: Supabase → Edge Functions → Secrets 에 `DATA_GO_KR_KEY` 등록
- **과거 공고 채우기**: `…/functions/v1/sync-bids?mode=backfill&days=7` 호출 (최대 31일, 24시간 호출 한도 있음)

## 알아둘 점
- 지역·금액·기관 조건은 서버에서 걸러내므로, 기간이 길고 조건이 느슨하면 유형별 최대 약 2,500건까지만 조회됩니다 (초과 시 화면에 안내).
- 공공데이터포털 응답이 느리면 24초 안에 받은 만큼만 보여주고 "일부만 조회" 안내를 띄웁니다 (Vercel 함수 30초 제한 방지).
- 같은 조건은 서버에서 3분간 캐시합니다. 개발계정은 보통 일일 호출 한도가 있어(서비스별 약 1,000건) 호출 수를 아끼기 위한 설정입니다.
- 금액 조건을 쓰면 추정가격·배정예산이 공개되지 않은 공고는 제외됩니다.
- 물품 공고는 금액 정보가 없는 경우가 있습니다.
